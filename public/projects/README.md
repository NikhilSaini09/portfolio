# Project Media Assets Directory

Place your project demo videos, GIFs, and screenshots into their corresponding folders:

- `kaali-tirri/`
  - `demo.mp4` or `demo.gif` (Multiplayer gameplay & host migration recording)
  - `screenshot-1.png`, `screenshot-2.png`
- `discord-platform/`
  - `demo.mp4` or `demo.gif` (Voice/video rooms & live text channels)
  - `screenshot-1.png`, `screenshot-2.png`
- `ai-crm/`
  - `demo.mp4` or `demo.gif` (LangGraph voice agent conversation & live form fill)
  - `screenshot-1.png`
- `3d-scene-sync/`
  - `demo.mp4` or `demo.gif` (Multi-window 3D physics synchronization across screens)
  - `screenshot-1.png`
- `sudoku-solver/`
  - `demo.mp4` or `demo.gif` (Computer vision photo recognition & 0.6ms solve)
  - `screenshot-1.png`
- `kanban-board/`
  - `demo.mp4` or `demo.gif`
- `budget-tracker/`
  - `demo.mp4` or `demo.gif`

### Supported formats
- **Videos**: `.mp4`, `.webm` (autoplays smoothly, muted, looping)
- **Animations**: `.gif`
- **Images**: `.png`, `.jpg`, `.webp`

The portfolio includes an automated fallback UI that renders a high-tech architectural visualization when media files are not yet placed.
