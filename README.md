# Nikhil Saini — Engineering Portfolio

Portfolio showcasing full-stack applications, real-time distributed systems, and competitive programming achievements. Built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4, and Lucide Icons.

## Tech Stack

- **Framework**: Next.js 16 (Turbopack, App Router, Partial Prerendering)
- **Language**: TypeScript 5 (Strict mode)
- **Styling**: Tailwind CSS v4
- **Components & Icons**: Custom Radix-style primitives, Lucide React, SVG brand icons
- **Video & Media**: Custom interactive video player with timeline scrubbing, seek buttons, and full-screen controls

## Featured Projects

1. **Kaali Tirri Web Multiplayer Game**: Serverless P2P multiplayer card game with WebRTC DataChannels, local validation, and graceful host migration on tab close.
2. **Discord-Style Real-Time Platform**: Full-stack text, voice, and video communication suite with LiveKit SFU, WebSockets, Prisma, and PostgreSQL.
3. **AI-First CRM**: Conversational assistant that converts unstructured meeting notes into database records via LangGraph and Llama 3.3 70B on Groq.
4. **3D Scene Multi-Window Sync**: Real-time cross-window 3D physics and spatial simulation via Three.js and the BroadcastChannel API.
5. **Image-Based Sudoku Solver**: Computer vision pipeline using OpenCV contour warping, CNN digit inference, bitmask backtracking, and solution overlay.
